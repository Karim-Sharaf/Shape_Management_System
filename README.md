# Shape Management System

Designed and implemented a robust geometric shape management application in C++ emphasizing core Object-Oriented Programming (OOP) design principles.

## 🚀 Key Features & Implementation
* **OOP Paradigms**: Leveraged inheritance and dynamic polymorphism to handle various geometric figures uniformly.
* **Geometric Classes**: Developed comprehensive class abstractions including Trapezoid, Parallelogram, and Sphere.
* **Software Architecture**: Applied strict object-oriented design patterns and decoupled logic (File Management, UI, and Shape models) inspired by UML concepts.

## 📂 Project Structure
* `Shape.cpp` / `Shape.h`: Base shape interface definitions and polymorphic implementations.
* `FileManager.cpp` / `FileManager.h`: Handlers for data persistence and text file I/O operations.
* `UI.cpp` / `UI_Main.cpp`: User interface console menus and driver execution logic.
* `users.cpp` / `Osama.cpp`: User entity modules and account tracking structures.
